# PICO-Humanoid

### **P**redictive **I**ntelligent **CO**ntrolled Humanoid Robot

**PICO-Humanoid** is a self-developed humanoid robotics research platform of the [**Predictive Intelligent Control Lab**](https://picontrollab.com/).

**PICO** = **P**redictive · **I**ntelligent · **CO**ntrolled
